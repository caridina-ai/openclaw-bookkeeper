## 關於更正類輸入詞

我有另一個 skill 是管理日常排程的，它在平時輸出物件時，都會順便顯示它的 ID，若要更正什麼時，就直接講它的 ID，讓 AI 可以直接操作 (若換成 script 則不必呼叫 AI)

例如 AI 顯示：

16:00 #285 運動
18:00 #286 晚餐

然後我就可以輸入「285 刪除」

同樣道理，如果用在我們的 skill 可能是這樣：

毛巾80
油漆刷25

然後系統的回應是

#358 雜費(毛巾) 80 餘 3328
#359 雜費(油漆刷) 25 餘 3303

我要更正的時候可以直接打

358 居住費
359 居住費

我覺得改科目是最常發生的，值得為它們設計一套方法

## 關於第二章無法辨識成格式的輸入詞

我看「矯正科目」的佔很大部分耶，我們提供「以 ID 更正」以後可以消除很多

啊！我發現「以 ID 更正」還有分成更正科目和更正名稱耶：

424 巷口饅頭   (改名稱)
423 居住費

我覺得 script 可以先判斷「巷口饅頭」不是科目名，代表要修改名稱

不然就請使用者配合，多加指明欄位好了：

424 名稱 巷口饅頭
423 居住費    (沒指定欄位且為科目，則判斷為修改科目)

### 妳建議可「免呼叫 AI」的幾種輸入詞

「把剛剛那批改成某科目」：我想用「指定 ID」解決

 `餘額多少？` 前面掛垃圾字（`怎麼了？有記嗎？餘額多少？`）：哎呀！如果我們有規範「標準語法」使用者(我)就不會再那樣打垃圾字了啦

 所以我覺得就認「餘額」就好了

 妳有講到刪除兩階段 rowid 的流程，我猜妳是說：

 「刪除剛剛那筆冰茶」，然後 AI 要先查到剛剛那筆冰茶的 rowid 才能刪除

 哈！如果套用我講的「以 ID」：
 
 286 刪除
 或
 刪除 286
 
 是不是一階段就做到了，而且 script 就做得到了
