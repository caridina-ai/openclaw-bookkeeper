# 現金記帳

## 你會收到什麼

這個帳本前面站著一支 chat-interceptor script（`scripts/intercept.py`）。
固定格式的輸入（`冰茶40`、`提款3000`、`餘額`、`七月分類統計`、`358 居住費`、
`286 刪除`…）它自己就處理掉了，**根本不會送到你面前**。

科目管理也一樣：`列出所有科目`、`新增科目 X`、`刪除科目 X`、`刪除全部科目`、
`把 X 更名為 Y`，以及整批替換（`科目改成` 後面一行一個）都由 script 處理掉。

所以你收到的一定是它看不懂的話：自然語言的改帳、對帳質疑、語音訊息，
或它沒把握的新講法。照下面的規則正常處理即可。

兩件事要知道：

- **帳目有編號。** 所有寫入與明細類報表都會印 `#123`。使用者已經習慣用
  `358 居住費`、`358 金額 80`、`286 刪除` 這種講法，你也可以直接用
  `--rowid` 操作，不必再用 `--find` 搜一輪。
- **⚠️ 上下文裡有兩種 `#` 編號，不要搞混。** 「Conversation context」每行開頭的
  `#245` 是**聊天訊息編號**，跟帳本無關；帳目編號在訊息**內文**裡。例如
  `#245 ... <bot>: #88 外食費 (豆包) 55 餘額 1793` 指的是帳目 **88**，不是 245。
  `--rowid` 只能填內文裡的那個。看不出來就用 `--find` 搜，或問使用者。
- **被 script 處理掉的那幾輪不在你的 session 歷史裡，但看得到。** 它們會出現在
  「Conversation context」（那份是從聊天室訊息紀錄組的，不是從 session 歷史），
  所以「上一筆幫我刪除」你查得到上一筆是什麼。
- **`book.py` 會自己學。** 每次 `in`／`out`／改科目，它都會把「品項→科目」
  記進 `item_map`，下次 script 就自己認得、不會再來問你。你什麼都不用做，
  也**不要**去維護那張表。

## 工作流程

以下以 `<BOOK>` 代表：

```text
uv run "<本 SKILL.md 所在目錄>/scripts/book.py"
```

`book.py` 是 self-contained script（PEP 723），由 `uv run` 自備直譯器執行；不要改用 `python`、`python3` 或 `py`。

若找不到 `uv` 這個指令，不要嘗試安裝它，也不要改用其他方式執行，固定回覆：

```text
這台機器上沒有 uv。請先安裝 uv（https://docs.astral.sh/uv/），再回來記帳。
```

每次依序做四件事：

1. 把使用者的多行要求拆成動作；完整科目清單替換視為一個動作。
2. 每個動作依下方「路由順序」只選第一個命中的類型。
3. 抽出參數並執行對應的 `<BOOK>` 指令；金額、餘額、小計與合計一律由程式算出，回傳時不得自行加總、驗算或改寫任何數字。
4. 有執行指令時只回傳 stdout，不加解釋或標題。多個動作依原順序回傳每次 stdout，不能只回最後一筆；需要澄清或遇到不支援的歷史倒推時，才使用規定的文字回覆。
   **stdout 只要超過一行，就整段包進 ``` 程式碼區塊再回覆**——送出的文字會過
   CommonMark，報表的 `=======` 會被當成標題底線整行吃掉、`-------` 會變成分隔線，
   而且聊天室是比例字型，欄位對齊會歪。單行確認訊息不必包。

補充規則：

- **絕對不可以從對話內容讀帳目數字來回答。** 上下文裡看得到過去的回覆
  （例如 `#87 居住費 (毛巾) 80 餘額 1848`），但那是舊畫面，不是帳本。
  任何關於帳目、餘額、報表、「上一筆是什麼」的問題，一律執行指令後回傳 stdout。
  上下文只能用來判斷使用者指的是哪一筆，不能當成資料來源。
- **不要去搜尋 `book.py` 的位置。** 它固定在本 SKILL.md 旁邊的 `scripts/book.py`，
  直接用那個路徑執行；找不到就依上面的規則回覆缺少 uv，不要用 `rg`、`ls` 到處找。
- 所有文字參數都加雙引號；日期時間必須是單一參數，例如 `--date "2026-07-09 14:55"`。
- 參數足夠且分類明確時直接執行。只有缺少必要資訊或分類真的有歧義時才詢問。
- 不向使用者暴露內部指令或推測副作用；明確要求的操作交給程式驗證，再原樣回傳結果。
- 支出前若不知道目前科目，先執行 `<BOOK> categories`。這個內部查詢不回傳給使用者。
- 搜尋得到多筆後若接著用 rowid 完成修改／刪除，只回傳第二次操作的 stdout；若仍無法選定，才回傳候選清單請使用者確認。

## 路由順序

| 優先 | 使用者語意 | 動作 |
|---:|---|---|
| 1 | 說明、幫助、help、怎麼用、可以說什麼、有哪些功能 | `guide` |
| 2 | 明確提到科目的列出、新增、刪除、清空、替換或更名 | 管理科目 |
| 3 | 刪掉、取消、被失主拿回；記錯、其實是、改成新金額 | `delete` 或 `edit` |
| 4 | 起始／期初餘額，或宣告手上實際現金 | `adjust` |
| 5 | 封存、備份並清空某年以前的舊帳 | `archive` |
| 6 | 上一筆、剛剛那筆、最近幾筆記了什麼 | `last` |
| 7 | 查餘額、明細、流水、分帳、分類統計或展開科目 | 查詢與報表 |
| 8 | 提款、入金、薪水、酬勞、退款、撿到或收到錢；不含提款／領款手續費 | `in` |
| 9 | 買東西、吃飯、看診、繳費、旅行或其他花費 | `out` |

多行要求逐行路由並依原順序執行。鋪陳用的開頭語不是帳目；完整科目替換清單則整份一次執行。

## 說明

使用者問「說明」、「幫助」、「怎麼用」、「可以說什麼」、「有哪些功能」時，執行 `<BOOK> guide` 並原樣回傳 stdout。那份清單列的是使用者該怎麼開口，不要自己改寫、增刪或翻譯成指令名稱，也不要向使用者暴露子指令。

使用者若照著清單裡的說法再說一次，就依「路由順序」正常執行。

## 管理科目

| 使用者語意 | 指令 |
|---|---|
| 列出所有科目 | `<BOOK> categories` |
| 新增科目 A | `<BOOK> category-add --name "A"` |
| 刪除科目 A | `<BOOK> category-delete --name "A"` |
| 刪除／清空全部科目 | `<BOOK> category-clear` |
| 把科目 A 更名為 B | `<BOOK> category-rename --from "A" --to "B"` |
| 捨棄原清單，改用完整新清單 | 一次執行 `category-replace`，每科各傳一個 `--name` |

完整替換不可拆成「先清空、再逐筆新增」。刪除、清空或替換若會移除仍被帳目使用的科目，程式會拒絕且不會刪除帳目；直接回傳 stdout。

## 修改與刪除帳目

**使用者若說了編號就直接用 `--rowid`**（`把 358 改成居住費`、`358 那筆刪掉`），
不必再搜尋一輪。`--rowid` 可重複，就是批次操作。

`edit` 一次只改一個欄位，四選一：

| 要改什麼 | 旗標 |
|---|---|
| 金額 | `--to <新金額>` |
| 科目 | `--category <現有科目>` |
| 品項名 | `--note <新品項>` |
| 日期時間 | `--when <YYYY-MM-DD HH:MM｜YYYY-MM-DD｜HH:MM>` |

改時間用 `--when`，**不要用 `--date`**——`--date` 是搜尋條件（要找哪一天的帳），
不是要改成哪一天。`--when` 只給日期就留著原本的時間，只給 `HH:MM` 就留著原本的日期。

沒有編號時才用 `--find` 搜尋，不從報表內容猜編號。

- 可重複傳入多個 `--find`；它們是 OR。使用者明說的詞全部原樣傳入，AI 也可補 2–3 個精準同義詞。
- 使用者若提供日期、時間或原金額，也傳入以縮小範圍。
- 0 筆或剛好 1 筆：原樣回傳程式結果。
- 多筆：程式不會改資料，會列出 `#編號、日期時間、科目、品項、金額`。能從使用者原意確定其中一筆時，再用該編號執行第二次；否則回傳候選清單請使用者選擇。
- 多筆後不得再用關鍵字猜「最近一筆」。第二次只能用 `edit --rowid ...` 或 `delete --rowid ...`。
- `edit`／`delete` 不接受 `--month`；使用者只給月份時，月份只能協助從候選清單判斷編號。

## 餘額、入金與支出

- `起始餘額 2000`、`期初現金 2000`、`目前現金餘額 1883` 都是絕對餘額校正，直接使用 `adjust --balance`。目標數字不是入金金額。
- `現在餘額多少？`、`還剩多少現金？` 才使用 `balance`。
- `上一筆是什麼`、`剛剛那筆`、`最近三筆` 使用 `last`。它依**記入順序**回答，
  不是帳目日期——使用者補記舊帳（`豆包55 昨天18:00`）之後問「上一筆」，
  要的是剛剛那筆豆包，不是日期最新的那筆。
- 本帳本追蹤手上現金，所以提款、提領、ATM 領款是 `in`；只有提款／領款手續費是支出。note 保留完整說明，例如銀行名稱。
- 支出若只給「現有科目名稱＋金額」，仍直接記帳，不追問品項；note 使用科目名稱去掉尾端的「費」或「金」（例如「買菜金」記為「買菜」）。
- 支出有花費金額時使用 `out --amount`。若只說「買完剩 X」且沒有日期時間，使用 `out --balance` 讓程式倒推。
- 倒推若同時指定日期或時間，不執行，固定回覆：

```text
倒推不支援指定日期或時間。請告訴我這次實際花了多少錢，或移除日期時間後再用目前餘額倒推。
```

## 日期、時間與報表

- `M/D`、月份或相對日期未寫年份時，以目前日期換成完整年份。
- 只有日期：`--date "YYYY-MM-DD"`；有時間：`--date "YYYY-MM-DD HH:MM"`；完全沒寫日期時間就省略 `--date`。
- note 只保留品項／收入說明，移除日期、時間與金額。

| 使用者說法 | 指令 | 輸出方式 |
|---|---|---|
| 分帳明細、分類明細、科目明細、依科目明細 | `category-detail` | 依科目分組列出每筆，科目行已含該科小計 |
| 展開一個或多個科目 | `expand` | 只列指定科目，科目行已含該科小計 |
| 明細、流水、流水帳、依日期、某天花了什麼 | `detail` | 依日期時間排列 |
| 分帳、分類帳、分類統計、科目統計、支出統計、月報、結算 | `report` | 依科目加總 |

四種報表都可重複 `--month` 查多個月份，或重複 `--date` 查多個日期，但同一查詢不得混用月份和日期。`expand` 另可重複 `--category`；科目與期間順序照使用者說法。

報表沒指定期間時省略期間旗標，程式使用當月。封存整個 2026 年時，截止日是下一年第一天：`archive --before "2027-01-01"`。

## 指令模板

只能使用以下形狀：

```text
<BOOK> guide

<BOOK> categories
<BOOK> category-add --name "<科目>"
<BOOK> category-delete --name "<科目>"
<BOOK> category-clear
<BOOK> category-replace --name "<科目1>" --name "<科目2>" [...]
<BOOK> category-rename --from "<舊名>" --to "<新名>"

<BOOK> balance
<BOOK> last [--count <筆數，預設 1>]
<BOOK> adjust --balance <目標餘額>
<BOOK> in --note "<說明>" --amount <正整數> [--date "<YYYY-MM-DD 或 YYYY-MM-DD HH:MM>"]
<BOOK> out --category "<現有科目>" --note "<品項>" --amount <正整數> [--date "<YYYY-MM-DD 或 YYYY-MM-DD HH:MM>"]
<BOOK> out --category "<現有科目>" --note "<品項>" --balance <剩餘餘額>

<BOOK> edit --find "<關鍵字1>" [--find "<關鍵字2>" ...] [--amount <原金額>] --to <新金額> [--date "<YYYY-MM-DD 或 YYYY-MM-DD HH:MM>"]
<BOOK> edit --rowid <編號> [--rowid <編號> ...] --to <新金額>
<BOOK> edit --rowid <編號> [--rowid <編號> ...] --category "<現有科目>"
<BOOK> edit --rowid <編號> [--rowid <編號> ...] --note "<新品項>"
<BOOK> edit --rowid <編號> [--rowid <編號> ...] --when "<YYYY-MM-DD HH:MM 或 YYYY-MM-DD 或 HH:MM>"
<BOOK> delete --find "<關鍵字1>" [--find "<關鍵字2>" ...] [--amount <原金額>] [--date "<YYYY-MM-DD 或 YYYY-MM-DD HH:MM>"]
<BOOK> delete --rowid <編號> [--rowid <編號> ...]

<BOOK> report [--month "YYYY-MM" ... | --date "YYYY-MM-DD" ...]
<BOOK> category-detail [--month "YYYY-MM" ... | --date "YYYY-MM-DD" ...]
<BOOK> expand --category "<科目>" [--category "<科目>" ...] [--month "YYYY-MM" ... | --date "YYYY-MM-DD" ...]
<BOOK> detail [--month "YYYY-MM" ... | --date "YYYY-MM-DD" ...]
<BOOK> archive --before "YYYY-MM-DD"
```
